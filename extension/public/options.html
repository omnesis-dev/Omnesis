Use the gateway's trusted HTTPS hostname (its Tailscale or mkcert certificate name). IP addresses are not accepted — the certificate covers the name, not the IP.

After a page stays focused for at least five seconds, Omnesis captures its URL, domain, title, readable page text, visit time, focused dwell time, stable browser device ID, and the Chrome profile name entered above. This can include content visible only after you sign in. Captures wait in a bounded local retry queue and are sent only to the gateway entered above. The gateway credential, browser device ID, queue, and recent delivery status are stored locally in this Chrome profile; the capture settings (pause, excluded domains) are stored on your gateway and shared by every browser paired to it. Incognito pages, sign-in pages and pages on excluded domains are never captured; you can pause capture, exclude domains, or unpair at any time. See the privacy policy.

Chrome page access is still granted, but capture is inactive while unpaired.
