is separate from that license: it aggregates the attribution and license notices
for **third-party** code and assets that Omnesis **distributes** — either bundled
directly in this repository, baked into a published `@omnesis/*` npm package, or
included in the Docker image. It exists so that anyone redistributing Omnesis can
satisfy the notice-retention requirements of the permissive licenses (MIT, BSD,
ISC, Apache-2.0, OFL) and the weak-copyleft licenses (MPL-2.0, LGPL-3.0) those
components carry.

It includes a Models.dev catalog notice and seven sections:

1. **Vendored browser libraries** — minified JS bundles committed under
   `packages/gateway/portal/vendor/` and served by the gateway's web portal.
2. **Bundled fonts** — the Inter typeface shipped with the portal, the iOS app,
   and the Android app.
3. **Bundled icon glyphs** — source-owned SVGs copied from Lucide.
4. **Browser-extension libraries** — code bundled into the Chrome extension.
5. **Docker client binaries** — the Docker CLI and its Compose plugin, copied
   into the published `omnesis-updater` image.
6. **iOS runtime dependencies** — SwiftDraw's native SVG renderer.
7. **Runtime npm production dependencies** — the transitive closure of production
   (non-dev) npm packages pulled in by the published `@omnesis/*` packages.

Copyright holders and license identifiers below were verified against each
package's own `LICENSE` file and `package.json` (and, for the vendored bundles,
the upstream project — **not** the license header currently embedded in the
minified file, which is a build artifact and does not reflect the upstream
license). Full license texts are not reproduced inline; each entry points to the
canonical upstream source where the complete text lives.

## 7. Runtime npm production dependencies

The published `@omnesis/*` packages (and the Docker image, which bakes in their
installed `node_modules`) pull in a transitive closure of third-party npm
packages as **production** (non-`dev`) dependencies. This closure was computed
from `package-lock.json` (lockfile v3) by taking every `node_modules/*` entry not
flagged `dev`, excluding the first-party `@omnesis/*` workspace packages, and
de-duplicating by `name@version`. It includes optional production dependencies
(e.g. platform-specific native binaries), so multiple platform variants of the
same library each appear as a distinct entry.

license expression:
