# Omnesis brand mark — source of truth

The mark is a broken ring ("O") whose lower-right opening dissolves into three
parallel rays. All assets derive from this single shape.

## Geometry (normalized to outer radius R)

- Outer radius R; inner radius r = 0.6610·R (concentric) -> ring thickness 0.3390·R
- Ray angle: -35.31deg
- Ray half-width: 0.0424·R ; 3 rays at perpendicular offsets 0.5553, 0.7010, 0.8467 ·R (even spacing 0.1457·R)
- Ring opening cut (parallel to rays) at 0.4521·R -> donut-edge↔line gap equals line↔line gap
- Top ray split by a centered gap; outer ray ends truncated by the outer circle, corners filleted (0.0291·R); gap-facing ends round-capped
- viewBox 0 0 1000 1000, mark centered at (500,500), outer radius 360

## Colors

- Brand blue: light #1F6FEB / dark #58A6FF (matches app accent pair)
- Demo orange: light #F97316 / dark #FB923C
- Mono: white #FFFFFF (on-color surfaces) / black #000000
