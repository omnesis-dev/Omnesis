The Decision model can now run on any decision model provider, set up from the portal, the iPhone and Android apps, or `omnesis decision`. Pick a provider from the presets — Ollaya or Ollama on this machine, or a hosted decision API (TypeSafe, OpenRouter, Ollama Cloud, Perplexity, Fireworks AI, Baseten, DeepInfra, Vercel AI Gateway, Cloudflare Workers AI, OpenAI, Microsoft Foundry, Fastino, AI/ML API) or any other System One server — and pick a model; the model lists come from each preset and the models.dev decision catalog. A provider is one backend with one key, serving its OpenAI-compatible API, its decision API, or both: adding OpenAI, Fireworks AI or OpenRouter sets up both, and a backend already set up for the agent gains its decision models without asking for the key again (`omnesis decision enable <backend>`). The decision API is the backend's `inference.backends.<key>.decision` block, assigned as `<backend>/<model>` on the stable path. A model is asked one test question when it is saved, so a model the server lacks or a refused key is reported then instead of by every decision failing. Every decision threshold is now a setting, defaulting to the value tuned on TypeSafe Jev: `enrichment.dates.worthThreshold` for email dates in time queries, which re-sorts the emails already judged from their stored scores when it changes, and `brain.thresholds` for each of the Brain's decisions. A model that scores higher or lower than Jev is brought in line by moving them. A chat model answering decisions now asks a few questions at a time instead of all at once.
