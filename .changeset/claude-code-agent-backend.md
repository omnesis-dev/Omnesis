Run the built-in agent on a Claude subscription through Claude Code. The new `claude-code/<model>` backend uses the operator's own installed and signed-in `claude` CLI (Claude Code 2.1.259 or later) on the gateway host; Omnesis never signs in to Claude or reads its credentials, and API-key variables are never passed to the CLI. It serves the agent, privacy-reviewer and image OCR roles; a CLI older than the minimum is reported as needing `claude update`. Each turn is an isolated `claude -p` process in an empty Omnesis-owned directory with every built-in Claude Code tool removed; Omnesis loads none of the operator's settings files, so no settings-enabled plugins, hooks or MCP servers, and fails the turn if Claude Code offers any tool outside Omnesis. Manage it with `omnesis claude-code status|refresh|setup-agent|remove` or under Settings → Models → Backends, and `omnesis doctor` reports `models.claude-code`. An interactive gateway install with `claude` on the PATH and no agent model offers to set it up with Haiku.
