Add `omnesis uninstall`, which removes Omnesis from the machine it runs on: everything it finds, or the components named — `gateway` (the user service, a hardened gateway through `sudo`, or a whole Docker install), `collector`, `openclaw`, `hermes`, `claude-code`, `codex` and `cli` (the installer's checkout, the global package, the launcher, the lock helper and the installer's PATH line). Data stays unless `--purge`, which also deletes the config directory, the service logs, the `dev.omnesis` keyring entries and a hardened gateway's state and passphrase, and is refused while anything that uses the data would stay. `--dry-run` shows the plan, `--yes` skips the confirmation, `--json` reports each step. Harness and client configs lose only their Omnesis entries; a checkout with local changes, a checkout or launcher the installer did not make and a PATH line other programs need are kept and reported. Every step is idempotent and a failed one never stops the rest, so running the command again finishes the job. On a Docker host the launcher performs the uninstall on the host, and `omnesis-gateway-admin uninstall` gains `--purge` and now also clears its build cache.
