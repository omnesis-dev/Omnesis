---
"omnesis": minor
---

The Omnesis account and the cloud connection are now available on every gateway, without setting an environment variable. Settings offers to connect the gateway to an Omnesis account, and `omnesis cloud` is always available in the CLI. A gateway you never connected keeps working as before; opening its Omnesis account page asks the relay only whether new accounts need an invite. A gateway connected earlier, while the setting was on, reconnects with the connection it saved; unlink it under Settings → Connectivity → Omnesis account if you no longer want it.
