Settings has a Connectivity tab on every gateway: one summary of how devices reach the gateway away from home, a page for each way in, and an optional step-by-step setup. Tailscale already on the gateway machine can be set up from the portal, which runs `tailscale serve` or `tailscale funnel` or shows the command to run; your own domain or reverse proxy is checked before it is saved; and the MCP server can be turned off on any address away from home.
