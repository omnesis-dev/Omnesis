The portal's Connect an agent dialog shows a grid of general agents, each with its own icon: Claude Code, Codex, ChatGPT, the Claude apps, Antigravity, OpenClaw and Hermes. Choosing one shows only that agent's setup, with the gateway's address filled in and a link to its section of the docs. Agents that connect from the Internet are marked with a warning on a private address, which they cannot reach, and the dialog then offers no command for them, only how to publish the gateway. OpenClaw and Hermes show the one-line installer and the `omnesis connect` command with a pairing code minted in place and, where the address presents the gateway's own certificate, its fingerprint. The Codex card and docs say that Codex 0.147 or later is needed to complete the sign-in. Claude Code offers the plugin first, as the recommended path, then the server alone. Claude Code and Codex say how to finish the sign-in on a machine without a browser, and the docs gain a section on it. Antigravity CLI replaces Gemini CLI, which no longer serves personal Google accounts. ChatGPT connects only on port 443, so its card warns when the address uses another port, and its note links OpenAI's developer mode guide. The step for the sign-in code says it applies only when the sign-in page shows one, and the page no longer repeats Connect an agent in its header while its empty state offers it. The access overview (`GET /admin/access`) now lists every MCP resource the gateway accepts, whether a client there meets the gateway's own certificate, and the certificate's fingerprint. The editor entries and the editor setup skill are gone; any other OAuth-capable MCP client still connects with the MCP URL.
