Find browser-openable Omnesis search results from the Chrome extension, with matching snippets, favicons, and actions to switch to an open tab or open the source link. Search access requires separate gateway-owner approval. The configured decision model can choose a read-only agent search for queries that need evidence, connections or calculations; the extension streams its text and tool activity alongside structured results.

Chrome page notes and Find are experimental: both controls and gateway endpoints require `OMNESIS_EXPERIMENTAL=1`, including previously approved browser credentials. Automatic capture and portal/mobile notes remain available by default.
