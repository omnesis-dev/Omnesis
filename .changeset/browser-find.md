Find browser-openable Omnesis search results from the Chrome extension, with matching snippets, favicons, and actions to switch to an open tab or open the source link. Find searches with its own read-only credential, which the gateway issues to the paired extension automatically. The configured decision model can choose a read-only agent search for queries that need evidence, connections or calculations; the extension streams its text and tool activity alongside structured results.

Chrome page notes and Find are experimental: both controls and gateway endpoints require `OMNESIS_EXPERIMENTAL=1`, including previously issued browser credentials. Automatic capture and portal/mobile notes remain available by default.
