Opening the Privacy page in the portal or the mobile apps no longer freezes the gateway for up to a second or more once agents have asked many questions. Each page of exchanges read the full agent transcript of every exchange on it, often megabytes each, though only a failed exchange whose own record names no cause is presented from it; it now reads a transcript only for those exchanges, and builds each page on a background reader instead of the thread every request waits on. The pages show exactly what they showed before.
