Capture a note about the current page from the Chrome extension using Tell Omnesis in the popup, the page or selection context menu, or Alt/Option+Shift+N. The side panel keeps the page and optional quotation with the draft, and unsent notes retry after an outage. Notes require separate gateway-owner approval; page capture keeps working with existing permissions. Gateways without the notes capability hide the feature, and existing extensions continue to capture pages.
