Asking the assistant about someone whose name also matches your own no longer leaves the conversation waiting for half a minute or more before it answers. To count a person's emails, chats and meetings, the people lookup read every one of their documents in full, which for your own record is most of the store. It now reads each document's type from a small index, so the same counts take well under a second. The gateway builds the index once when it first starts after the update, which adds about a minute to that start on a large store.
