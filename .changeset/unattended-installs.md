The installer run without a terminal (by a script, or by an AI agent on your behalf) takes the answer Enter would give wherever a question has one: the default embedding model, and under `--docker` encryption at rest with a generated passphrase file. It prints each default with the flag that changes it, and prints the recovery code as words rather than JSON. Its output is plain text when it is not a terminal, and `omnesis model install` draws its progress bar only on a terminal. A Docker CLI found off PATH no longer comes with advice to open a new terminal first: the `omnesis` command finds it there.
