`omnesis secure` on an install that is already encrypted no longer takes a backup or restarts anything, and reports an already-encrypted set of secret files as nothing to do. The backup's file list lines up its sizes past long names. A native collector beside a Docker gateway sends `omnesis-collector status` and the other gateway commands to `omnesis`, the gateway's own command on that machine. The installer waits long enough for a collector's first start, keeps npm's audit and funding notices out of a source install, and reports each launcher it writes once.
