# CLA signatures

CLA signatures are maintained automatically by CLA Assistant in
[`signatures/cla.json` on the `cla-signatures` branch](https://github.com/omnesis-dev/Omnesis/blob/cla-signatures/signatures/cla.json).
That file is the authoritative signature register.

To sign, follow the bot's instructions on your pull request. See
[the contribution guide](../CONTRIBUTING.md#license-and-contributor-license-agreement)
and the [CLA](../CLA.md).
