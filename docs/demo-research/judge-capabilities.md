# Independent candidate judge: capability and evidence feasibility

All 45 candidates in `candidates.md` were judged against the actual tool and source surfaces audited in `omnesis-capabilities.md`. Scores are 1–5: clarity (C), everyday value (V), wow (W), differentiation (D), and privacy/governance emphasis (P). Privacy scores reflect the proposed video, not merely the fact that Omnesis stores a private corpus. These are editorial judgments, not measured user reactions. No production data was consulted.

Feasibility: **Ready** means supported source/tool composition, still requiring genuine live-agent validation. **Conditional** names an extra operational dependency, untwinned source, or host action. Neither means the demo has already passed. Every row identifies minimum evidence and the visible reveal; the last column names the weak-claim/false-positive risk.

## Selection implications

The strongest evidence-rich everyday hooks are C01, C02, C03, C05, C06, C07, C08, C09, C15 and C30. However C06/C30 compete for the same finance reveal; C08/C44 compete for the same genuine transcription scene. Do not select all high totals mechanically. C11 supplies relative-date breadth; C17 or C41 supplies an off-calendar social commitment; C19 or C45 supplies a real governance scene. C04 is particularly good for showing an external assistant's division of labor, provided fictional destination routing is handled honestly and the maps action is genuinely external.

C01 needs externally filled DOCX output; C03 needs real watch relay validation; C05 must state association; C08/C09 need actual generated binaries through production transcription/OCR. Those dependencies are acceptable and should be built, not disguised with pre-normalized fixture prose. The code inventory shows missing synthetic coverage for Photos, motion, local files, several agent transcripts and extension capture. “Everything” coverage needs explicit safe work beyond the existing twin set.

The live-agent rehearsal must be fresh inference on corpus data with no replay conversation or answer-key document. Citation quotation verification does not certify chronology, refund matching, relationship identity or causal explanation; those need independent authoritative assertions for the scene. Privacy-enabled external rehearsals are additionally required because built-in success does not prove Answer disclosure success.
