criteria. Raw assessments are in `judge-architecture.md`,
`judge-capabilities.md`, and `judge-competitors.md`. Each criterion is 1–5;
combined totals are out of 75. Diversity and a visible everyday-life payoff
justify including lower-scoring concepts; this is not a mechanical top-15 list.
All concepts still require runtime proof. None implies competitor incapability
when equivalent evidence is available to that competitor.

## Runtime acceptance

Each concept needs a prompt card, expected-facts ledger, exact evidence IDs,
explicitly covered data range, distractors and a verified response. Recording
must use a real configured agent, never a scripted answer. A successful built-in
turn does not establish successful Answer disclosure or external DOCX writing;
validate those paths separately. Cerebras timing must be measured on the
configured recording model; Luna testing establishes factual feasibility only.
