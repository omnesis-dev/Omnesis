# Support

Thanks for using Omnesis. Here's where to go for what:

- **🐛 Bug reports & ✨ feature requests** — open a
  [GitHub issue](https://github.com/omnesis-dev/Omnesis/issues/new/choose) using
  one of the templates.
- **💬 Questions, help, and ideas** — start a
  [GitHub Discussion](https://github.com/omnesis-dev/Omnesis/discussions).
- **🔒 Security vulnerabilities** — **do not** open a public issue. Follow the
  private disclosure process in [`SECURITY.md`](SECURITY.md).
- **📖 Documentation** — user and operator docs live at
  [omnesis.dev/docs](https://omnesis.dev/docs).

## Before you post

Omnesis indexes your **private digital life** — emails, messages, contacts,
health, files. When asking for help or filing a bug, **never paste real personal
data**: redact logs and screenshots, and reproduce with fictional examples. The
bug-report template has a reminder and a checkbox for this.
